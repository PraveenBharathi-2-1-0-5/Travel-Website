# 🌍 Abscond – Travel Website

**Abscond** is a responsive travel website designed to help users explore destinations, discover hotels, and plan their next adventure through a clean and user-friendly interface.

## ✨ Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Modern Navigation Bar:** Includes the brand logo, search bar, and relevant navigation buttons.
- **Destination Search:** Allows users to search for cities and travel destinations.
- **Search Filters:** Includes options such as price range and ratings.
- **Hotel Listings:** Displays hotel information in an organized card layout.
- **Attractive UI:** Features a modern layout with visually appealing sections.
- **Responsive Footer:** Provides useful links and additional website information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## 🎯 Project Objective

The main objective of this project is to develop a responsive travel website while improving practical skills in front-end web development, page layout design, and responsive styling.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Explore the website and test its responsive layout.

## 📱 Responsive Design

The website uses CSS media queries and flexible layouts to provide a consistent browsing experience across different screen sizes.
